Applied Technology Schools

Developed over approximately six months

Overview

A web platform that provides organized information about Applied Technology Schools and the educational opportunities they offer.

Problem / Motivation

Information about schools and educational opportunities is extensive and changes over time. The platform aims to present it clearly and in one place.

How it works

Content is organized into a structured hierarchy so users can move through it with clear navigation and find school information without searching across scattered sources.

Technologies / Components

Front-end web development. No other technologies are specified for this project.

Development notes

The main challenges were presenting a large amount of information clearly and keeping content maintainable as it changes.

What was learned

Practical web development, information architecture, structuring and maintaining content, and designing for usability.

02

Software / Data interpretation

Medical Laboratory Results Analysis Application

Overview

A software application that lets users enter laboratory test results and understand them in simple language. It is rule-based and does not use artificial intelligence.

Problem / Motivation

Laboratory results are technical and difficult for most people to read.

How it works

Each entered value is compared with its normal/reference range and classified as within range, higher, or lower. The result is then shown in plain language with informational guidance.

Technologies / Components

Rule-based data processing and conditional logic.

What was learned

Input handling, logical classification, and presenting technical information in a user-friendly way.

Informational software tool only. It does not replace professional medical advice, diagnosis or consultation.

03

Arduino / Assistive technology / Embedded systems

Smart Cane

Overview

An Arduino-based assistive project that helps detect obstacles and gives the user feedback.

Problem / Motivation

A traditional cane senses only what it touches. This project extends it with sensors for the surrounding environment.

How it works

Obstacle detection. Multiple ultrasonic sensors monitor different sides of the cane.

Feedback. Detected conditions can trigger vibration and/or buzzer alerts.

Environmental detection. A water sensor and hole detection extend the system beyond front obstacles.

Visibility. Reflective tape makes the cane more visible outdoors, near roads and in low light.

Technologies / Components

Arduino, ultrasonic sensors, vibration feedback, buzzers, water sensor, hole detection sensor, reflective tape, and additional sensors/components.

What was learned

Sensor integration, combining several inputs in one embedded system, and hardware prototyping.

04

Electronics / Security system

Laser Alarm System

Overview

A simple electronic alarm that reacts when a laser beam is interrupted.

How it works

A laser beam is aimed at an LDR. When the beam is interrupted, the LDR detects the change in light level, which triggers the alarm circuit and activates the buzzer. LEDs give visual status indication.

Components

Laser, LDR, buzzer, LEDs.

What was learned

How light-dependent sensing works and how a basic circuit turns a change in light into an alert.

06

Artificial intelligence / Computer vision / Object detection

YOLOv8 Vandalism Detection

Overview

An object detection model, YOLOv8m, trained to detect vandalism in images and video. The dataset is vandalism123-3, with one class.

How it works

YOLO models look at an image once and predict bounding boxes with confidence scores. The model was trained on the dataset and then evaluated on standard detection metrics.

Reported evaluation metrics

≈ 0.984mAP@50
≈ 0.851mAP@50–95

Reported project results. The model is not claimed to be deployed in production.

Preparing and using a dataset, training an object detection model, and interpreting mAP metrics.

07

Physics / Arduino / Sensor measurement

Ultrasonic Distance Measurement System

Completed

01 — Overview

A completed Arduino-based physics and measurement project that measures the distance between an ultrasonic sensor and an object and shows the result on a small LCD screen. It is a simple, practical application of ultrasonic sensing, distance measurement, and digital display.

02 — How it works

The ultrasonic sensor measures the distance to an object. The Arduino Nano processes the measurement, converts it into the display units, and sends it to the LCD.

03 — Hardware

Confirmed components: Arduino Nano, a common ultrasonic distance sensor, and a small LCD display.

04 — Measurement

The measured distance is displayed in two units: centimeters (cm) and meters (m).

05 — Technical concept

The sensor sends an ultrasonic pulse toward an object and measures the time the reflected sound wave takes to return. Because sound travels at a known speed, that time gives the distance. The pulse travels to the object and back, so the distance is half of the full path.

06 — What was learned

  • Working with sensors
  • Reading physical measurements
  • Microcontroller-based measurement
  • Converting measurement units
  • Displaying sensor data
  • Connecting physical phenomena with software and electronics
